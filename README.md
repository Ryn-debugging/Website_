# LaporWarga

Platform web responsif untuk pelaporan kerusakan infrastruktur dan fasilitas umum lingkungan secara digital, transparan, dan terdokumentasi.

## Teknologi Utama (Phase 1)

- **React 19** (JavaScript)
- **Vite 8**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **React Router DOM v7**

## Menjalankan Aplikasi Secara Lokal

1. Pastikan **Node.js** sudah terpasang.
2. Pasang seluruh dependency:
   ```bash
   npm install
   ```
3. Jalankan server pengembangan:
   ```bash
   npm run dev
   ```
